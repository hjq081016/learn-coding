## 题 1　读代码（8 分钟）

打开 `q1_buggy.py`，**不要运行它**。回答：

1. 这段代码执行到 `for` 那行时，会发生什么？把 `print` 的结果写出来（正常输出 / 报错）。
2. 如果报错，报错发生在第几行？
3. 怎么改才对？（可以给两种写法）

## 题 2　写代码（15 分钟）

新建 `诊断/wordcount.py`，要求命令行运行 `python wordcount.py data.txt`：

- 读入文件，按空白切词，统计每个词出现次数
- 打印出现最多的**前 5 个**词及次数，一行一个
- 结果同时写进同目录的 `out.txt`
- **文件不存在时不许崩**，打印一句人能看懂的话，正常退出
- 文件是空的也要能处理
- 自己造一个 `data.txt` 用来测试（内容随意，20 个词以上）

## 题 3　概念（2 分钟）

用你自己的话，各不超过两句：

1. `list` 和 `dict` 的区别是什么？什么场景用哪个？
2. `try / except` 是在解决什么问题？不用它会怎样？

## 题 4　审代码（5 分钟）

打开 `q4_ai_code.py`——假设这是 AI 替"你"写的代码，**它能跑通**。

列出至少 **2 个坑**，每个说清：坑在哪一行、会导致什么后果、你怎么改。
